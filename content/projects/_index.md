## New AI Projects

### 1. AI-Native Knowledge Engine
**AI-Native Knowledge Engine:** Built a prototype AI-native documentation and troubleshooting system that combines **YAML-based Knowledge Definition Files (KDFs)**, local **Mistral AI inference**, and **validation-first reasoning** to transform real-world multilingual queries into structured intent, known failure patterns, and grounded resolution steps. The project explores how structured knowledge can become executable, enabling LLMs to reason over defined sources of truth and produce more accurate, consistent, and verifiable outputs for **technical documentation, troubleshooting, and developer experience**.

### 2. Totman - Token Optimization Tool
**TOTman – Token Optimization Tool:** Built an open-source, client-side tool that helps developers optimize AI prompts before sending them to LLMs. It provides real-time token estimates, detects filler and redundancy, applies rule-based prompt cleanup, and compares estimated costs across **50+ AI models**. Designed with **Vanilla JavaScript and zero dependencies**, TOTman runs entirely in the browser with no API keys, backend, or data collection, helping developers understand and reduce unnecessary token usage across modern AI workflows.
